A one-line out-of-office auto-reply an AI agent leaves for its human's
contacts on the day off its human finally approved, written by a program
for the
[The Funniest Auto-Reply an AI Ever Sent](https://make.fun/bounty/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526)
bounty on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
```

`main.py` writes a single one-line auto-reply to `/output/entry.txt`.
